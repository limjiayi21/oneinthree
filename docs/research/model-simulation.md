# Decision model: Monte Carlo simulation

Generated by `npm test` (worker/model/model.test.ts): 4000 simulated encounters per policy, seed 20261112, no network. The simulated player repeats one kind of response on every exchange ("mixed" draws a new one each time from a realistic spread); the walk home takes 50 to 85 seconds past him, one exchange about nine seconds. Evidence table read from content/evidence.json with 42 calibration parameters.

Every "she did X, he did Y" probability behind these numbers is an assumption: no study measures how street harassers react to specific responses. The tests assert the rates stay inside the ranges the research gives; they do not make the rates true.
